# Prompt Preservation

The exact LLM prompts are part of the experimental record.

Do not regenerate them from these documentation files.

Copy the exact prompt bodies verbatim from the scripts that produced the canonical outputs.

Required files:

- `gemini_pair_audit_v3.txt`
- `security_relevance_v1.txt`

After copying, verify that their version identifiers match the output metadata/configuration.

If the prompt text differs from what the canonical output-generating script used, record the discrepancy rather than silently replacing it.
